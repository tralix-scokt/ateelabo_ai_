# Ateelabo AI - Starter Project

This project is a ready-to-run React + Vite + Tailwind template with a simple serverless API route for proxying OpenAI requests.

## Quick start

1. Rename `.env.example` to `.env` and add your `OPENAI_API_KEY`.
2. Install dependencies: `npm install`
3. Run the dev server: `npm run dev`
4. Open `http://localhost:5173`

## Deploy

- For Vercel: push to a repo and set `OPENAI_API_KEY` in Environment Variables.
- For Netlify: use functions or a serverless adapter and set env var likewise.
